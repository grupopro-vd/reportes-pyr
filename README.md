# Reportes PYR · Grupo Pro

Página de inicio instalable (PWA) para los formularios de Prevención de Riesgos:
Flash Report rápido, Declaración de accidente o incidente (con DIAT) y Flash Report detallado.

Los formularios y el envío de correos siguen en Google Apps Script; esta página solo los abre
dentro de una app con el logo de Grupo Pro para instalar en la pantalla de inicio del teléfono.
